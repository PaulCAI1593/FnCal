## 二、这一版改了什么

1. **日程列表日期列也画图标**：节日 `flag`、节气 `sun`；此前这一行只有文字，颜色一律主题色。
2. **节日与节气各一套颜色，界面统一**：节日 `--accent`，节气 `--term-ink`（主题色互补色）；图标只写 `currentColor`。六处对齐：月视图日号行、周/四日/日全天条、日程列表日期列、日程列表事件行、事件详情卡、迷你月历（0.6.9 起已无副文字）。
3. **详情卡节日图标**：`.view__color--holiday` 由 `--text-3`（灰）改为 `--accent`。
4. **日程列表日期列「周X · M月」不再折行**：`white-space: nowrap`；≤430 用 `--fs-xs` + `letter-spacing: -0.01em`，不折「月」、不省月份、不改列宽（96px；≤360 仍是 60px + 10px 字号）。
