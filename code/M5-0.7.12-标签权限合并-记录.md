## 2. 权限模型（`code/app/lib/ai-grants.mjs`）

- `TAG_MODE_FIELDS = { write: 'tagWriteMode', delete: 'tagDeleteMode' }`；`TAG_OPS` 仍是 `['create','update','delete']`（MCP 三个操作不变）。
- `normalizeCredentialLimits()` 只产出两项，值只接受 `direct`，其余落 `proposal`（默认提案）。
- `tagWriteModeOf(credential)`、`tagDeleteModeOf(credential)` 读一项；`canTagWrite(credential, op)`：`delete` → 删除项，`create`/`update` → 新建与编辑项，未知 op → `proposal`。
- **旧字段**：`tagCreateMode` / `tagUpdateMode` 读到即忽略，不迁移、不报错（0.7.11 未对外发布，不需要兼容）。
- 与日历 grants 无关：两项只跟 AI 接入总开关与本字段走。

`code/app/lib/ai-store.mjs`：`publicCredential()` 回读两项；`createCredential()`、`updateCredential()` 的白名单循环只含两项。PATCH 里带旧字段 → 200、不落盘、不改现值（测试锁定）。

## 3. 网页端（`code/web/src/js/ai-settings.js`、`calendar.css`）

- 标签块两行：
  - `tagWriteMode`：标题 `settings.ai.tagMode.write`「新建与编辑」，`data-tag-op="write"`；
  - `tagDeleteMode`：标题 `settings.ai.tagMode.delete`「删除」，`data-tag-op="delete"`。
- 选项顺序「直接通过 → 提案」与日历 `writeRow` / `deleteRow` 完全一致；默认都「提案」。
- 切「直接通过」仍走 `confirmAction({ danger: true })` 二次确认；取消回滚、不发请求。
- `refreshModeAvailability()` 只按「AI 接入是否开启」禁用，不看日历写档（标签是全局注册表）。
- 分隔线：`const permissionsDivider = el('div', { class: 'ai-editor__divider', 'data-ai-divider': 'permissions', 'aria-hidden': 'true' })`；`bodyEl` 顺序 `… 字段开关, 操作方式, 分隔线, 标签权限, 对话内代办批准 …`。
- 样式（`calendar.css:3470`）：`.ai-editor__divider { height: 0; margin: 0; border-top: 1px solid var(--border); }` —— 只画 1px，不写上下 margin；上下 24px 由 `.ai-editor__body` 既有 flex `gap: var(--sp-6)` 提供，避免与 gap 叠加。`aria-hidden` 让它不进无障碍树。

## 9. 偏差（实现与派单文字的差异，均已按规格意图处理）

| # | 偏差 | 处理与理由 |
| --- | --- | --- |
| 1 | 删除行标题用「删除」，不是「删除标签」 | 派单写的就是「删除」，且与日历「删除」行同字；`deleteHint` 保留「会清掉所有日程与任务上的这个标签」，语义不丢 |
| 2 | 分隔线不写 margin，上下 24px 来自既有 `.ai-editor__body` flex `gap` | 派单建议 20–24px；用既有 gap 避免与块间距叠加成 48px，且不新造组件 |
| 3 | 390/320 下两行是「标签在上、单选组在下」的堆叠布局 | 这是 `.settings__row` 既有的窄屏行为，日历两组同款；未改布局，只验证不挤、不重叠（vGap 12、无溢出） |
| 4 | 分隔线对比度 1.17（浅）/ 1.25（深） | 装饰性分隔，沿用 `--border`；提到 3:1 会抢眼，与「加个分隔符、不抢眼」口径相反。除分隔线外无其他控件依赖该对比 |
| 5 | 旧字段 `tagCreateMode` / `tagUpdateMode` 传进 PATCH 返回 200 而非 400 | 0.7.11 未发布，不迁移也不惩罚旧客户端；字段被忽略、不落盘（测试锁定） |
| 6 | 证据页临时取消 `.ai-editor__footer` 的 sticky | 只作用于证据页，避免底栏遮住标签块；源码未改，测量不依赖该行 |
