## 1. 改前根因（§S1）

0.1.0 / 0.2.0 的 APK 由 CI 的 `gradle assembleDebug` 产出，Android 插件在 CI 机器上
每次重建 `~/.android/debug.keystore`（私钥随机），所以两次构建的签名证书不同。
安卓只允许同签名包覆盖安装，于是「检查更新」下载的新包会装不上、或只能卸载重装。

补救范围：0.1.0 / 0.2.0 已发出去的包无法改签名，只能让用户卸载一次；
0.2.1 起固定签名，之后同签名版本可直接覆盖。

## 4. 沉浸式（§S2-2b）

三页统一走 `ShellChrome`：

- `applyWindow`：`WindowCompat.setDecorFitsSystemWindows(window, false)`；
  `statusBarColor` / `navigationBarColor` = 透明；API 29+ `isNavigationBarContrastEnforced = false`；
  `WindowInsetsControllerCompat.isAppearanceLightStatusBars / …LightNavigationBars`
  按 `uiMode` 取反（浅色主题深色图标，深色主题浅色图标）。
- `applyInsets(root)`：根容器 `shell_root` 的 padding 统一由监听器写
  `top = systemBars.top`、`bottom = max(systemBars.bottom, ime.bottom)`；
  布局里不写死 `paddingTop`，也不加 `fitsSystemWindows`。
- 三个页面接入：地址页 / 关于页在 `setContentView` 后调
  `applyWindow` + `installBlurLayer` + `applyInsets(findViewById(R.id.shell_root))`；
  主界面调 `applyWindow` + `applyInsets`（WebView 内容留在安全区内，底部栏可点）。
- 键盘：`windowSoftInputMode="adjustResize"` + `ime` insets 计入底部内距，
  只压内容区，地址页输入框不被盖。
- API 24–28：`WindowCompat` 与 `ViewCompat` 自动用旧 flag 兜底，不崩、不错位
  （**未在真机验证**）。
