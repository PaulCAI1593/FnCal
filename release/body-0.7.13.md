## 0.7.12 — 标签权限合并（2026-11-11）

### 变更

- **标签权限从三组并两组**：「新建与编辑」「删除」，与日历权限的分组方式一致。`create_tag` 与 `update_tag` 共用「新建与编辑」，`delete_tag` 只受「删除」控制；每行仍是「提案 / 直接通过」，默认提案。
- **日历权限与标签权限之间加一条分隔线**，两套权限不再连成一串。
- 旧字段 `tagCreateMode` / `tagUpdateMode` 废弃，统一为 `tagWriteMode`。旧凭据读到旧字段即忽略，按默认「提案」处理。
- 技能包升到 0.7.12，权限表与工具说明同步。

### 说明

- 0.7.11 未对外发布；本版只合并权限分组，不改工具名、参数与提案格式。
- 标签名上限仍是 12 字。

## 0.7.11 — AI 标签权限（2026-11-10）

### 新增

- **AI 凭据可管标签**：新增三项权限——新建标签、编辑标签（emoji / 名称 / 分组）、删除标签。每项两档：提案（先出待审提案，通过后才写入）与直接通过，默认提案。三项与日历读写权限无关：标签是全局的，只读凭据也可以按这三项操作。
- **MCP 三个新工具**：`create_tag`、`update_tag`、`delete_tag`；`tag` 参数接受 id 或名称。提案模式下只返回提案 id，注册表不动。
- **标签提案**：「AI 提案」列表能显示新建 / 编辑 / 删除三类；新建显示「emoji + 名称」，编辑显示「旧 → 新」，删除显示影响条数。受理时若标签已被改过，会提示重新发起。
- 技能包随本版发布（`skill-v0.7.13`），文档同步三个工具与权限表。

### 说明

- 标签名上限仍是 12 字，与注册表一致。
- 删除标签会清掉所有引用事件的标签与分类，包括该凭据不可见的日历；这一步写入审计日志。
- 0.7.10 已对外发布；本版只加 AI 标签权限，不改 0.7.10 的界面与数据格式。
